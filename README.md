# 2D Platformer Game

A browser-based 2D platformer with procedurally generated terrain, built with vanilla JavaScript, HTML5 Canvas, and CSS — no frameworks, no external dependencies.

**[Play it live](https://quantumcommit45.github.io/platformer_game/)**

## Overview

- Player currently moves around the world; can break and place blocks

## Features

- Procedural 2D world generation, including cave carving and restart logic
- Ore/resource generation across terrain tiles
- Real-time physics (gravity, jump arc, platform collision detection)
- Keyboard and mouse input handling
- Custom rendering via HTML Canvas
- CSS-based user interface

## Tech Stack

- JavaScript (Canvas API)
- HTML5 / CSS3
- Hosted via GitHub Pages
